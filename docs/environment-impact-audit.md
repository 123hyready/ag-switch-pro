# AG Switch Pro 环境影响检查（2026-10-15）

检查范围：当前 app 源码、Windows 本机只读版本探测及 Codex 配置解析。未访问其他电脑；未执行安装、卸载、环境变量清理或恢复。

## 结论
存在让 Codex 无法使用的路径；尚无证据表明意图路由直接破坏 Node 安装。不能承诺程序完全不影响全局环境。

1. 路由投影修改 Codex config.toml 和自有模型目录。旧版已实际发生缺 support_verbosity 导致整个 Codex 启动失败；修复已交付。
2. 异常终止可能留下 localhost 代理配置。正常退出 detach_all 对恢复失败仅记录日志，随后仍可能停代理；cleanup_before_exit 还会无条件记录恢复完成。因此正常退出恢复失败也可能导致客户端指向已关闭端口。
3. env_manager 的环境变量清理会删除 HKCU/HKLM 环境变量，默认检测限定 OPENAI/ANTHROPIC 等前缀，不包含 PATH；但删除和恢复入口没有变量名白名单校验，不能将其视为绝对禁止修改 PATH。备份可能包含凭据，请勿公开上传。
4. 工具管理的安装/更新确实会运行包管理器命令，修改全局 Codex 包。安装中断、权限或文件锁有造成 CLI 不可运行的可能。并非路由必经步骤；POSIX 另有先卸载后安装修复逻辑，Windows 此修复分支禁用。
5. 原生 Codex 登录刷新会回写 auth.json，与 Codex 跨进程并发只有比较后替换，未形成跨进程事务，存在登录状态竞争窗口。

## 本机结果
node v24.9.0；npm 11.6.0；codex-cli 0.160.1。Get-Command 指向 E:/nodejs。codex features list 退出码 0，当前配置可解析。这些结果不证明其他电脑或过去版本安全。

## 后续定位需要
受影响电脑的具体错误、使用的 EXE 版本或 SHA256、是否点击过安装/升级或清理环境变量。只收集变量名、程序路径与脱敏错误，不收集密钥、auth.json 全文或完整环境变量值。
