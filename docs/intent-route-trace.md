# 意图路由过程记录

最近路由记录按每个模型请求展示三个步骤：

1. 判断：保存当时配置的判断模型。模型判断、观察模式和判断失败回退分别显示；阶段保持、重复请求、预算耗尽等注明本次未调用判断模型。
2. 选择：保留最初选中的工作模型及理由，观察模式另列建议模型。执行回退不会覆盖这个初始选择。
3. 执行：按顺序记录工作模型、供应商、耗时，以及正在请求、请求失败或上游已接收。第二次尝试标记为回退。

页面每 5 秒更新记录，展开请求信息可查看时间、记录 ID、路由组 ID 和会话 ID。旧版记录缺少判断模型和执行尝试时明确标注未知，不根据当前配置补造历史。

“上游已接收”表示转发层已拿到响应，不等于 SSE 流已结束，也不表示编码任务已经验证成功。此版本执行耗时为取得上游响应前的耗时，不含后续流式输出；应用意外退出时可能保留“尚未记录结果”。记录不保存用户提示词、模型思考过程或凭据。
